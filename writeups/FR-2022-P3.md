### Guided Solution

This problem has a rather unique appearance.
Usually, problems of this flavour come with only a single functional equation, but here we are given two conditions.
The fact that the function is defined on the positive integers only is also noteworthy and
will likely be crucial at some point in the solution.
Going forth, consider any function $f\colon\mathbb{N}\to \mathbb{N}$ that satisfies both of them.

The first condition states that for all $m,n\in \mathbb{N}$, we have

\begin{equation}\label{A}
    f(f(m)f(n)) = mn. \tag{$\ast$}
\end{equation}

The form of this equation is very typical for this type of Olympiad problem. On the other hand,
the second condition is more unusual, and states that for all $a\in\mathbb{N}$, we have

\begin{equation}\label{B}
    f(2022a + 1) = 2022a+1. \tag{$\dagger$}
\end{equation}

This just tells us that $f$ has many *fixed points* at which applying $f$ has no effect.
Concretely, this happens for all the integers greater than $1$ with a
remainder of $1$ when divided by $2022$.

Trying some simple candidate functions, the only one we find to satisfy
both conditions is the identity function $f(n) = n$.
While there is not much we can do with \eqref{B} alone,
it hints at the possibility that the identity function is the only possible function;
after all, any other function that has this many fixed points would be quite a strange function indeed...

In contrast, there are many things we can do with \eqref{A}, which
motivates us to focus solely on this condition for a while.
A basic strategy for functional equation, is to substitute some particular values.
The simplest substitution in \eqref{A} is to set $m = n = 1$, which yields

\begin{equation}\label{c}
    f(c) = 1, \quad\text{where } c = f(1)^2. \tag{1}
\end{equation}

This is very useful, since it tells us that $f$ attains $1$ as a value somewhere.
We probably do not care much about the exact point where this happens, just that it happens somewhere.
Thus, to keep things nice and clean, we introduced the new variable $c$.

It is now very natural to make a substitution like $m = c$ in \eqref{A}. Because of \eqref{c},
this greatly simplifies the nested expression on the left and we deduce that

\begin{equation}\label{invc}
    f(f(n)) = cn. \tag{2}
\end{equation}

This tells us that applying $f$ twice in a row always acts just like multiplication by $c$.
But we know that $f$ has many fixed points, at which applying $f$ twice has no effect at all!
This means that we must have $c = 1$. Going back to \eqref{c} and \eqref{invc},
we conclude that

\begin{equation}\label{one}
    f(1) = 1, \tag{3} \\
\end{equation}

and

\begin{equation}\label{inv}
    f(f(n)) = n. \tag{4}
\end{equation}

A function that satisfies property \eqref{inv} is called an *involution* and has many nice properties.
In particular, all the positive integers that are not fixed points of $f$ can be paired up such that $f$
sends each number in a pair to its partner. Running with they hypothesis that the identity function is the only
solution, we just need to show that there are no such pairs, implying that all positive integers are fixed points.

So far, we have not really used the full generality of \eqref{A} yet.
Motivated by \eqref{inv}, we try to make a repeated application of $f$ appear.
One way to achieve this is to apply $f$ to both sides of the equation \eqref{A}.
Using \eqref{inv} to simplify the resulting expression, we deduce that

\begin{equation}\label{mul}
    f(m)f(n) = f(mn). \tag{5}
\end{equation}

But this fact greatly restricts the structure of $f$. To determine the value of $f$
at some number, it suffices to factor that number as a product, and determine the value of $f$ on the two factors.
Repeatedly applying \eqref{mul}, we can also generalise this argument to a product of more than two factors.
But our function is defined over the positive integers, and every positive integers can
be broken down as a product of primes.
Thus, the behaviour of $f$ is uniquely defined by its behaviour on the prime numbers.

If we could show that every prime number is a fixed point of $f$, then we could conclude that $f$ is the identity.
To this end, consider an arbitrary prime $p$.

By \eqref{inv} we know that $f(f(p)) = p$, in particular it is a prime number.
This motivates us to express $f(f(p))$ as a product: Let us write $f(p) = st$ for some $s,t \in \mathbb{N}$.
If we apply $f$ to both sides of this equation and use \eqref{mul}, we find that $p = f(f(p)) = f(st) = f(s)f(t)$.
This implies that $f(s) = 1$ or $f(t) = 1$, so let us assume without loss of generality that $f(s) = 1$.
But now \eqref{inv} and \eqref{one} imply that $s = f(f(s)) = f(1) = 1$.
Thus, no matter how we write $f(p)$ as a product, one of the two factors must be $1$.
We conclude that

\begin{equation}
    f(p) \text{ is prime}. \tag{6}
\end{equation}

We now just have to rule out the possibility that $f$ maps $p$ to some other prime $q\neq p$.
Assume that this happens.
